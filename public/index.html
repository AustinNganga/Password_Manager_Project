1. What an attacker sees on disk

Keys are HMAC tags, not domain names. Every ciphertext has the same length, so password lengths leak nothing.



2. Swap attack
Swaps the encrypted records of two sites, with no checksum supplied. AES-GCM binds each record to its own site tag, so the swap fails.




3. Rollback attack
Restores the previous saved version and loads it against the checksum kept on your device. Change a password first so an older version exists.


4. Wrong password and tampering
Sign out and enter a wrong master password: load fails the password check. Clear this device's checksum below, sign in again and the rollback check turns off (the swap defense still works).
